The website has a logo. Where the page shows the business's name as its mark, write it as
<span class="site-logo">Business name</span>, and leave its size to the page. In an ad that is
the page name beside the avatar; in an e-mail or a page, the header. The span holds the name and
nothing else, and stands on its own: never inside a sentence, never followed by more words
("Gift Card Plugin" is written as plain text). The real logo replaces the name, so put no icon of
your own beside it.
