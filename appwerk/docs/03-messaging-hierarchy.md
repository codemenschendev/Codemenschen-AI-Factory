# 03 — Messaging Hierarchy

## Message priority ladder

Ordered by what must land first. If a visitor retains only N messages, they must be the top N.

1. **Category:** You can license an exclusive app that real users have already paid for. (The "I didn't know this was possible" moment.)
2. **Mechanic:** You buy an exclusive license with revenue rights — not IP, not equity. We build, promote, and run the app for you under an agreed roadmap and a monthly retainer.
3. **De-risking fact:** Every app is validated before listing — real people paid real money during a real test. Historical actuals, shown per app.
4. **You need nothing technical:** No code, no developers to hire, no ops. That's our job — it's what the retainer pays for.
5. **Exclusivity as literal fact:** One buyer per app. When it's licensed, it's gone from the catalog. (Fact, never countdown.)
6. **Honest risk:** Apps can fail. You can lose what you put in. Here is exactly what happens on failure, non-payment, or exit (resale, 5% fee).
7. **Who we are:** Codemenschen, a Vienna web development company, working in the open — published methodology, real contract, real Impressum.

Rule: message 6 may never be more than one scroll away from message 1. Honesty is load-bearing, not appended.

## Hero message options (compliant)

Each = headline + subline + CTA. All pass the guardrails: no ownership-of-business framing, no income promise, no urgency.

**Option A — Category-first (recommended)**
- H1: "License and back your own app."
- Sub: "We build apps, validate them with real paying users, and license each one exclusively to a single backer. We keep building, promoting, and running it for you."
- CTA: "See how it works" · secondary: "Browse available apps"

**Option B — Capability-first**
- H1: "Software and AI, without writing a line of code — or hiring anyone."
- Sub: "License an app that real users have already paid for. Our Vienna studio develops and operates it under an agreed roadmap. One buyer per app."
- CTA: "See how it works"

**Option C — Evidence-first**
- H1: "Every app here has already been paid for by real users."
- Sub: "We validate before we list. You license one exclusively — we build, promote, and run it. Apps can still fail; we tell you exactly how that works too."
- CTA: "Browse validated apps"

Testing note: A vs C is the real experiment (category curiosity vs. proof-led). B is fallback if A/C confuse. A variant only "wins" if downstream comprehension holds (measured via FAQ/support-question rate and withdrawal rate, per 01-website-strategy).
